这是什么？

这是一个返回舱为主题的模组，它添加了一个返回舱，不过以后可能就不止一个了
返回舱的作用是为绝境中的玩家提供援助（大多数意义上），但为平衡性做了一些取舍
它可以给你带来各种各样的物资，不过这部分的平衡性无法保障
目前添加了一个巡航弹与测试用途的人形，可能会入正

你是否有希望面对SRP或Spore（需要噩梦等附属才能算强）等强大的敌人？
你是否更希望享受纯粹的战斗与博弈而非被机制恶心到无法动弹、失去武器？
不想用神器，却打不出有效伤害，没有办法反制？
我们很快就会修正这些问题，

后续规划：
返回舱在草方块上呆得太久，模型会长草
返回舱在雪地群系太久会有雪
会像结构一样刷已经降落的返回舱
有降落伞和推进器的安全降落的返回舱与运输舱
更平衡的设计
运输舱以后会改建模的！
