这是一个返回舱模组，它添加了一个返回舱，不过以后可能就不止一个了

返回舱的作用是为绝境中的玩家提供援助（大多数意义上），但为平衡性做了一些取舍

它可以给你带来各种各样的物资，不过这部分的平衡性无法保障

后续规划：

返回舱在雪地群系太久会有雪
会像结构一样刷已经降落的返回舱
有降落伞和推进器的安全降落的返回舱与运输舱
